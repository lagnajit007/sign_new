# Hand-shape reference images

`A.svg` … `Z.svg` are the "Sign language X.svg" files from Wikimedia Commons
(https://commons.wikimedia.org/wiki/File:Sign_language_A.svg and siblings),
originally from WPClipart (http://www.wpclipart.com/legal.htm).

Licence: **Public domain** (checked per file via the Commons API on 2026-11-19;
all 26 files report `LicenseShortName: Public domain`). No attribution is
required; this note is kept for provenance.

The images show American Sign Language (ASL) fingerspelling, matching the
alphabet the recognition model was trained on. Number signs (0–9) have no
consistent public-domain set yet, so lessons show the digit instead.
